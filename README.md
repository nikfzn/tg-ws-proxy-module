# TG WS Proxy Модуль для KernelSU

Локальный Telegram MTProto прокси для KernelSU с автозапуском и перезапуском.

## Что делает

- запускает прокси при загрузке
- держит процесс живым через `service.sh`
- сохраняет `SECRET` в `secret.conf`
- использует `config.conf` для настроек
- скачивает нужный бинарник автоматически
- управляется через `control.sh`
